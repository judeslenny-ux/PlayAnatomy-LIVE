PLAYANATOMY LIVE - VERSION SERVEUR (recommandée pour un groupe)

IMPORTANT: cette version NE peut PAS fonctionner sur Netlify Drop seul: elle utilise un vrai serveur Node.js pour synchroniser les telephones.

DEPLOIEMENT SUR RENDER (compte gratuit selon disponibilite):
1. Creez un depot GitHub et mettez-y TOUS les fichiers et dossiers de cette archive, a la racine.
2. Dans https://dashboard.render.com/ : New > Web Service > choisissez votre depot.
3. Runtime Node, Build Command "npm install", Start Command "npm start".
4. Une fois deploye, utilisez l'URL https://...onrender.com.
5. Professeur: SOY EL PROFESOR > CREAR PARTIDA.
6. Joueurs: scannez le QR dans la salle > saisissez nom > ENTRAR.
7. Presenter: EMPEZAR > REVELAR RESPUESTA > SIGUIENTE.
8. Classement seulement a la fin, avec export CSV.

LIMITATIONS: le plan gratuit de Render peut mettre les services en veille; une premiere ouverture peut etre lente. Les parties sont en memoire: un redemarrage du serveur perd la partie. Gardez le navigateur professeur ouvert. Testez sur deux appareils avant une session.
